# Viora

A full-stack video sharing platform with creator channels, authentication, subscriptions, playlists, comments, likes, and cloud media management.

## Features

- User authentication with JWT
- Access and refresh token handling
- User profiles and channels
- Avatar and cover image uploads
- Video management
- Comments and likes
- Subscriptions
- Watch history
- RESTful APIs

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Cloudinary
- Multer

## Installation

Clone the repository:

git clone <repository-url>

Install dependencies:

npm install

Create `.env` file using `.env.sample`

Run the server:

npm run dev
